# Aion UA

Український фан-сайт для гравців Aion: онлайн серверів, розклад подій, калькулятори, лічильники для стріму
й локалізація. Відкривається на <https://juniorapi.github.io/aionua/> (GitHub Pages з гілки `main`).

З 5.10.2026 це нова версія (дизайн «Безодня»): вона переїхала з папки `v2/` у корінь, на старі адреси
сторінок. Старий дизайн лишився в історії git.

## Сторінки

| Сторінка | Файл | Що вміє |
| --- | --- | --- |
| Головна | `index.html` | онлайн трьох серверів наживо, найближчі події, пошук інструментів (клавіша `/`), покажчик усіх інструментів, банер локалізації |
| Розклад | `schedule/index.html` | шкала «Сьогодні» з лінією поточного часу, тижнева таблиця, перемикач EuroAion / Origin Aion / AionDestiny, фільтри категорій; сервер у посиланні: `schedule/?server=origin` |
| Кристали, стрижні, божики | `crystal_crafting/index.html` | три калькулятори рецептів: матеріали на один крафт і на партію до 999 крафтів |
| Біжутерія | `craft/index.html` | калькулятори біжутерії й матеріалів, точки збору дарриту, опалу, сераміуму, давнього ефіру й фоніки |
| Сувої, зілля, їжа | `spc/index.html` | чотири калькулятори з ефектами предметів; однакові назви рецептів підписані матеріалом чи пропорцією |
| Енергокінез, ефірокінез | `essencetapping/`, `aethertapping/` | ресурси за расою, регіоном і рівнем навички, пошук, координати `[pos:…]` з кнопкою копіювання |
| Стигми 4.6 і 4.8 | `stigma/`, `stigmas/` | сторінки в дизайні сайту, а сам калькулятор — оригінальний, у рамці: перемикач версії й мови, для 4.8 — ряд класів; збірка живе в адресі сторінки (`stigma/#код`, `stigmas/#клас/код`); на телефоні 4.6 зменшується цілком, а 4.8 ставить слоти над списком |
| Калькулятор чар | `aion-4.6-enchantment-calculator/index.html` | шанс для кожного з 41 рівня каменю за рідкістю, рівнем предмета й зачаруванням |
| Конвертер ефіру | `efir/index.html` | сяючий, чистий і очищений ефір у звичайному магічному |
| Solution / Hammer Counter | `tempering-solution-counter/`, `ice-hammer-counter/` | налаштування оверлею (мова підпису, фон, свій підпис), посилання для OBS, прев'ю з кнопками; сам оверлей — `overlay.html` |
| Локалізація | `localization/index.html` | інсталятори клієнтів із версією, розміром і датою з релізу GitHub, скрипти перекладу сайтів, інструкція |

Калькулятори стигм — оригінали з `stigma/calculator/` і `stigmas/<клас>/` у рамці. Усередині рамки вони
ховають власний фон, кнопку «Назад» і підвал (`embed.js` у їхніх папках), а посилання на збірку беруть
у сторінки через `window.stigmaShareLink`. Відкриті напряму (старі закладки), вони переходять на сторінку
сайту з тією самою збіркою. Нові сторінки збираються з компонентів `DESIGN.md`.

### Старі адреси

- `euroaion/`, `originaion/`, `aiondestiny/` ведуть на `schedule/?server=euro|origin|destiny`;
  файли `schedule.json` у цих папках лишаються — їх пише збирач;
- `v2/…` веде на ту саму сторінку без `v2/`, з параметрами й `#збіркою` (у `v2/` лише перенаправлення);
- `tempering-solution-counter/` і `ice-hammer-counter/` в OBS (`window.obsstudio`) одразу показують
  `overlay.html?lang=en` з тим самим числом: так джерела «Браузер», налаштовані на стару сторінку,
  працюють без змін;
- `stigma/calculator/` і `stigmas/<клас>/`, відкриті напряму, — див. вище.

## Звідки дані

Сторінки нічого не збирають самі:

- онлайн: воркер `aionua-online.borsay86.workers.dev` (код у `worker/`), запасний варіант `data.json`;
- розклади: `euroaion/schedule.json`, `originaion/schedule.json`, `aiondestiny/schedule.json`
  (їх оновлюють `fetch_online.py` і `destiny_schedule.py` у GitHub Actions, `.github/workflows/fetch.yml`);
- рецепти й точки збору: `<інструмент>/data.json`, перенесені зі скриптів старих сторінок;
  іконки предметів — у `<інструмент>/images/`;
- лічильники: число в `localStorage` під ключами старих сторінок (`waterCount`, `hammerCount`),
  тож рахунок переходить разом зі стрімером;
- локалізація: запасні версії й дати — `localization/dates.js` (його оновлюють разом
  із релізом), справжні — з релізу `localization` через GitHub API; скрипти `*.user.js`
  лежать у `localization/`, бо їхні `@updateURL` ведуть на
  `raw.githubusercontent.com/juniorapi/aionua/main/localization/…`, тобто саме на цей шлях
  у репозиторії. Через raw, а не Pages: Pages розгортається GitHub Actions, і під час збою
  Actions (5.10.2026) оновлення стояли в черзі; raw віддає файл із гілки за ~5 хв без Actions.

Правила відображення онлайну (коли ховати число, коли стверджувати «офлайн») пояснені в коментарях
`assets/js/online.js`.

## Як подивитися локально

Сторінки чекають, що сайт лежить у підпапці `/aionua/`, як на GitHub Pages. Найпростіше:

```sh
mkdir -p /tmp/site && ln -sfn "$PWD" /tmp/site/aionua
npx http-server /tmp/site -p 8080
# відкрити http://localhost:8080/aionua/
```

Воркер онлайну відповідає на `localhost:8080`, тож онлайн буде живий і локально.

## Тести

```sh
node --test tests/*.e2e.mjs
python3 -m unittest tests/test_destiny_schedule.py
```

Потрібен Playwright. `site.e2e.mjs` (головна й розклад) підставляє власні дані й фіксує час, тож не
залежить від того, що зараз у `data.json` і розкладах; `tools.e2e.mjs` звіряє розрахунки інструментів з їхніми
`data.json`; `stigma-calculators.e2e.mjs` перевіряє сторінки стигм з оригінальними калькуляторами (збірку
в адресі, класи, мову, заточку, українські підказки, телефон); `redirects.e2e.mjs` — старі адреси.
