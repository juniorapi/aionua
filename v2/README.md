# Aion UA v2 — новий дизайн

Окрема папка для нової версії сайту. Основний сайт у корені репозиторію не змінено:
обидві версії працюють поруч, поки нову не доведуть до ладу.

Після злиття в `main` нова версія відкриється на <https://juniorapi.github.io/aionua/v2/>.

## Що вже є

| Сторінка | Файл | Що вміє |
| --- | --- | --- |
| Головна | `index.html` | онлайн трьох серверів наживо, найближчі події, пошук інструментів (клавіша `/`), покажчик усіх інструментів, банер локалізації |
| Розклад | `schedule/index.html` | шкала «Сьогодні» з лінією поточного часу, тижнева таблиця, перемикач EuroAion / Origin Aion / AionDestiny, фільтри категорій; сервер у посиланні: `schedule/?server=origin` |
| Кристали, стрижні, божики | `crystal_crafting/index.html` | три калькулятори рецептів: матеріали на один крафт і на партію до 999 крафтів |
| Біжутерія | `craft/index.html` | калькулятори біжутерії й матеріалів, точки збору дарриту, опалу, сераміуму, давнього ефіру й фоніки |
| Сувої, зілля, їжа | `spc/index.html` | чотири калькулятори з ефектами предметів; однакові назви рецептів підписані матеріалом чи пропорцією |
| Енергокінез, ефірокінез | `essencetapping/`, `aethertapping/` | ресурси за расою, регіоном і рівнем навички, пошук, координати `[pos:…]` з кнопкою копіювання |
| Стигми 4.6 | `stigma/index.html` | порожні й закриті слоти видно одразу, як у грі; значки класів, раса й рівень; звичайні стигми з рівнем доступу й дві гілки покращених поруч; покращена стигма ставиться разом із потрібними; ранги, осколки й Очки Безодні; підказка з описом українською; адреса лишається чистою, код збірки з'являється в ній лише зі стигмами й сумісний зі старим `/stigma/#…` |
| Калькулятор чар | `aion-4.6-enchantment-calculator/index.html` | шанс для кожного з 41 рівня каменю за рідкістю, рівнем предмета й зачаруванням |
| Конвертер ефіру | `efir/index.html` | сяючий, чистий і очищений ефір у звичайному магічному |
| Solution / Hammer Counter | `tempering-solution-counter/`, `ice-hammer-counter/` | налаштування оверлею (мова підпису, фон, свій підпис), посилання для OBS, прев'ю з кнопками; сам оверлей — `overlay.html` |

Стигми 4.8 поки відкриваються зі старого сайту (`../stigmas/`).
Їх можна переносити по одній сторінці, беручи компоненти з `DESIGN.md`.

## Звідки дані

Нова версія нічого не збирає сама — вона читає ті самі джерела, що й старий сайт:

- онлайн: воркер `aionua-online.borsay86.workers.dev`, запасний варіант `../data.json`;
- розклади: `../euroaion/schedule.json`, `../originaion/schedule.json`, `../aiondestiny/schedule.json`
  (їх оновлює `fetch_online.py` у GitHub Actions);
- рецепти й точки збору: `<інструмент>/data.json`, перенесені зі скриптів старих сторінок;
  іконки предметів беруться зі старих сторінок (`../../crystal_crafting/images/…`), копій немає;
- стигми 4.6: дані й українські тексти старого калькулятора (`../stigma/js/data.js`, `vals.js`,
  `lang_*.js`) і його іконки. Сторінка підключає ці файли як є, тож переклад правиться в одному
  місці — `stigma/js/lang_uk.js`. Мовні файли зливаються через `$.extend`, для цього є крихітна
  заглушка `assets/js/tools/legacy-shim.js` замість jQuery;
- лічильники: число в `localStorage` під ключами старих сторінок (`waterCount`, `hammerCount`),
  тож рахунок переходить разом зі стрімером;
- локалізація: запасні версії й дати — `../localization/dates.js` (його й далі оновлюють разом
  із релізом), справжні — з релізу `localization` через GitHub API; скрипти `*.user.js`
  лишаються в `../localization/`, бо на ці адреси вказують їхні `@updateURL`.

Правила відображення онлайну (коли ховати число, коли стверджувати «офлайн») перенесені з `index.html`
основного сайту разом із поясненнями в коментарях `assets/js/online.js`.

## Як подивитися локально

Сторінки чекають, що сайт лежить у підпапці `/aionua/`, як на GitHub Pages. Найпростіше:

```sh
mkdir -p /tmp/site && ln -sfn "$PWD" /tmp/site/aionua
npx http-server /tmp/site -p 8080
# відкрити http://localhost:8080/aionua/v2/
```

Воркер онлайну відповідає на `localhost:8080`, тож онлайн буде живий і локально.

## Тести

```sh
node --test tests/v2.e2e.mjs tests/v2-tools.e2e.mjs tests/stigma-model.test.mjs
```

Потрібен Playwright (як і для решти тестів у `tests/`). Тести головної й розкладу підставляють власні дані
й фіксують час, тож не залежать від того, що зараз у `data.json` і розкладах; тести інструментів
звіряють розрахунки з їхніми `data.json`. Модель стигм перевіряється без браузера: коди посилань
у тестах зняті зі старого калькулятора тими самими діями.
