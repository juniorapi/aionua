# Безодня — дизайн-система Aion UA v2

Токени живуть у `assets/css/v2.css` (`:root`), тут — правила, як ними користуватися.

## Огляд

Темний, стриманий інтерфейс для гравців, які тримають сайт поруч із клієнтом гри ввечері.
Атмосферу дають не градієнти й сяйва, а три речі з лору Aion:

- **Вежа Вічності** — тонкий розколотий шпиль у герої: верх крижаний (Елізея), низ багряний (Асмодея), між ними золоті уламки Безодні.
- **Розподіл фракцій** — смуга Асмодіани / Елійці біля кожного сервера.
- **Золото ефіру** — єдиний акцент на весь сайт.

## Кольори

| Токен | Значення | Навіщо |
| --- | --- | --- |
| `--bg` | `#0a0b10` | фон сторінки |
| `--surface` | `#0f1118` | панелі, блоки |
| `--raised` | `#171a23` | вибране, наведення, підказки |
| `--sunken` | `#0c0d13` | підкладка сегментованих перемикачів, рядки груп |
| `--line` / `--line-strong` | `#1f2330` / `#2b3040` | розділювачі / контури панелей |
| `--line-control` | `#585e73` | контури полів і перемикачів (контраст ≥ 3:1) |
| `--text` / `--text-2` / `--text-3` | `#eceaf0` / `#a7a9b8` / `#8a8da0` | основний / другорядний / підписи (усі ≥ 4.5:1 на фоні) |
| `--gold` | `#e2b865` | **єдиний акцент**: головна дія, вибраний стан, фокус, «зараз» |
| `--asmo` / `--ely` | `#d8583f` / `#8fcbf0` | **лише дані фракцій**; розрізняються й за світлістю, не тільки за відтінком |
| `--live` | `#5ed39a` | стан «онлайн», завжди разом із підписом |

Глибина — сходинками поверхонь і лініями, без тіней у спокої. Тінь має тільки випадний список пошуку.

## Типографіка

- **Bona Nova 400** — заголовки й назва сайту. Польський шрифт із повною кирилицею (Ґ, Є, І, Ї).
  Ніколи в кнопках, підписах, бейджах і цифрах.
- **Geologica 400/500/600** — усе інше: текст, інтерфейс, числа. Цифри завжди
  `font-variant-numeric: tabular-nums` — окремий моно-шрифт не потрібен.
- Шкала: 64 (h1) · 44 (розділи) · 32 (панелі) · 26 (групи) · 19 (лід) · 16 (текст) · 15 (рядки інструментів) · 13 (підписи) · 12 (мітки великими літерами).
- Заголовок героя — не більше двох рядків на десктопі. `text-wrap: balance` для заголовків, `pretty` для абзаців.
- Українські множини через `Intl.PluralRules("uk-UA")`: 1 гравець, 3 гравці, 1 289 гравців.

## Розкладка

- Контейнер 1280 px, поля `clamp(16px, 5.5vw, 80px)`, відступ між розділами 96 / 64 / 48 px.
- Герой: текст і пошук ліворуч, Вежа між колонками, панель «Сервери зараз» праворуч.
- Розділи не повторюють один одного: панель подій (блок), покажчик інструментів (без карток, лише лінії), банер локалізації (золотий контур).
- Щільні сторінки-інструменти (розклад, калькулятори) — таблиці й шкали з лініями-розділювачами, без карток.

## Компоненти

- **Кнопка головна** — золото, темний текст, 48 px заввишки. Одна на екран.
- **Чип** — посилання-кнопка 44 px з контуром `--line-strong`.
- **Сегментований перемикач** — сервери; вибраний сегмент на `--raised` з контуром.
- **Бейдж** — 22 px, радіус 6. Золотий для «Нове», «Оновлено», «Популярне»; нейтральний для категорій.
- **Статус сервера** — крапка + слово: «онлайн» (пульсує, лише коли дані живі), «офлайн» (порожнє кільце, лише за явним сигналом джерела), без підпису, поки стан невідомий.
- **Смуга фракцій** — дві частини з проміжком 3 px, під нею легенда з числами й відсотками.
- **Рядок інструмента** — назва, необов'язковий бейдж, стрілка; при наведенні текст золотіє, стрілка зсувається на 3 px.
- **Подія** — «зараз» із золотою смугою прогресу й «ще N хв»; «далі» з часом і «через N хв».
- **Шкала розкладу** — блоки: минулі тьмяні, поточні золоті, майбутні нейтральні; золота лінія «зараз».
- **Лічильник** — «− число +» 48 px, кнопки вимикаються на межах, поле приймає лише цілі.
- **Калькулятор рецепта** — панель: ліворуч вибір предмета (іконка 40 px у рамці), професія чи ефект, лічильник крафтів; праворуч таблиця «На 1 крафт / Разом», підсумок «Результат крафту» золотом.
- **Список збирання** — рядки «рівень · назва · кількість точок» під заголовками регіонів; вибраний рядок із золотою рискою ліворуч. Координати `[pos:…]` — єдине місце з моноширинним шрифтом: так видно межі рядків.
- **Шанси каменів** — 41 рядок стовпцями згори вниз: рівень, смуга шансу, відсоток; найкращий камінь золотий.

## Рух

Один продуманий момент: поява героя (текст знизу вгору з кроком 80 мс) і прорисовка Вежі.
Далі — лише відгук: 150 мс на наведення, `scale(0.98)` на натискання. Сторінки-інструменти без анімацій появи.
`prefers-reduced-motion: reduce` вимикає все, крім змісту.

## Так / Ні

**Так:** один акцент; реальні дані замість прикладів; підписи біля кожного кольорового сигналу;
елементи керування ≥ 44 px; видимий фокус (золота рамка 2 px); `Intl.*("uk-UA")` для дат і чисел.

**Ні:** фіолетові чи неонові градієнти, сяйва за героєм, градієнтний текст, скло «для краси»;
сітки однакових карток з іконкою над заголовком; дрібні надписи над заголовками;
сітки й смуги на фоні; моно-шрифт «для технологічності»; вигадані цифри; емодзі.

## Адаптивність

- ≤ 1180 px: герой в одну колонку, Вежа ховається, інструменти у 2 колонки.
- ≤ 900 px: меню розділів за кнопкою, події в одну колонку.
- ≤ 640 px: інструменти в одну колонку, назва й стан сервера стовпчиком, шкала й таблиця розкладу прокручуються вбік із закріпленою першою колонкою.
- Сторінки інструментів: ≤ 1180 px рецепт і збирання в одну колонку, координати розкриваються під вибраним ресурсом; ≤ 640 px рядки ефіру у два поверхи, рідкість предмета 2 × 2.

## Як розширювати

Нова сторінка інструмента в `v2/<назва>/index.html` підключає `../assets/css/v2.css`, ту саму шапку й підвал,
і складається з наявних компонентів. Новий колір чи шрифт — спершу сюди, потім у `:root`.
